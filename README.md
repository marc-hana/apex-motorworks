# Apex Motorworks

A responsive automotive workshop marketing website built with React + Vite.

## Run locally
1. Install Node.js (LTS).
2. Open this folder in a terminal.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL printed by Vite.

## Build for deployment
Run `npm run build`. Upload the project to GitHub and import the repository into Vercel. Vercel should detect Vite automatically; use `npm run build` and `dist` as the output directory.

## Before using for a real client
- Replace the Apex Motorworks name, contact information, address, service details and pricing.
- Replace the demo Unsplash images with client-approved photos.
- Connect the appointment form to a backend or form service. It currently demonstrates client-side validation and a success state only; it does not send or store submissions.
- Add the client's real social media links and business hours.
- Confirm all service claims and prices with the business owner.
